# Portfolio of Miloslav Jezek

### 👀 Why
Lately I haven't liked that I can't show anything I do at my current job. So the main motivation behind this small piece of digital space is to show what I can do. It's not about satisfying exhibitionism - which I'm not inclined to. 

My intentions with this portfolio are:
- To feel good about work I create that isn't "kept in the drawer" (read: private GitHub repos)
- To have a more personalised self-presentation than a LinkedIn profile
- To be able to easily show what I do to non-developers or people not familiar with GitHub

### 🛠️ How
The portfolio is made in `VueJS` so I don't need to repeat myself when reusing some elements. Most of the code is actually `HTML` & `CSS`. I may make the portfolio more eye-catching in the future, but for now I want to keep it as simple as possible and focus on personal projects.
